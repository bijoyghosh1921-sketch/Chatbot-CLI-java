# Chatbot CLI Java

An interactive Java terminal application that connects to a local Ollama instance 
and uses native Windows PowerShell for text-to-speech output.

## Project Notes
- Developed as a learning project to explore Java `HttpClient`, `ProcessBuilder`, 
  and local AI integration.
- Code architecture and implementation generated with assistance from AI pair-programming.
- Built and tested locally on Windows using Java 11+ and Ollama.
